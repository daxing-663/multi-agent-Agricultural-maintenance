# 诊断 Agent 作业手册（SKILL v0.1）

## 一、假设清单（三类必须逐条落到"确认 / 排除 / 无法评估"）

| 类别 | 常见假设 | 对应工具 |
| --- | --- | --- |
| 生物 | 真菌/卵菌/细菌性病害、虫害、线虫 | `query_pest_disease_library(crop, symptom)` |
| 非生物 | 缺水/渍水、盐渍化、缺素或肥害、药害 | `query_soil_reference(site_id)`、`query_agronomy_knowledge(question)` |
| 设备与环境 | 阀/泵/风机故障、控制失灵、通风不足、结露 | `query_equipment_manual(device_id, fault_code)` |
| 观测系统自身 | 采集链路未接入、探头漂移、门限错误 | 由感知报告的数据质量段佐证 |

## 二、鉴别配方（按顺序）

1. `query_pest_disease_library(crop, symptom)`：症状描述要带部位与形态
   （例："叶片、暗绿色水渍状、自叶缘起始"），不要只写"叶子有问题"；
2. `query_soil_reference(site_id)`：拿土壤本底与近期读数对照；
3. `query_equipment_manual(device_id 或型号, 故障码/现象)`：设备侧假设必须查到条目；
4. `query_agronomy_knowledge(question)`：管理层面的问题（水肥、湿度控制）；
5. `get_treatment_options(诊断结论摘要)`：**最后**再取方案，摘要里必须包含诊断名。

## 三、置信度口径

| 置信度 | 成立条件 |
| --- | --- |
| high | 有直接证据（症状 + 环境条件 + 知识库鉴别要点三者互证），且关键通道齐全 |
| medium | 有直接症状证据但缺 1 条互证链（如缺土壤/设备数据），或存在 1 个未排除的竞争假设 |
| low | 只有间接证据、关键通道缺失、或证据之间互相矛盾 |

影响范围：能给出面积/株数/台数就给数字与口径（如"约 15% 叶面积、相邻 3~5 株"），
给不出就写"无法量化，原因是××"。

## 四、转人工条件（满足任一条即写"须转人工"）

- 知识库对某诊断名返回未命中/无方案（锚点校验不通过）；
- 方案涉及药剂剂量、稀释倍数、安全间隔期而知识库未给出；
- 三类假设均无法评估（证据整体缺失）；
- 出现"诊断结论与安全约束可能冲突"的迹象（如禁限用物资）。

## 五、报告自检清单

- [ ] 三类假设都显式处理，写"已排除"的给了理由；
- [ ] 每条判断都有"证据来源"（通道 + 时间，或知识库条目名）；
- [ ] 处置方向只引用知识库原文，没有自造药剂/用量/间隔期；
- [ ] 给了成立条件与证伪条件（"若观察到 ×× 则应改判"）；
- [ ] 建议补检项具体到部位/通道/方法，可供中枢决定是否补诊断。
